# 0024. 라이선스와 배포 방식

상태: 확정 (2026-11-02, #192)

## 결정

- 공개 저장소는 AGPL-3.0-only 그대로 둔다. 소스 공개 의무 없이 쓰려는 기관에는 같은 코드를 상용 라이선스로 따로 제공한다(이중 라이선스).
- 배포는 기관 안에 설치하는 형태만 한다. 기관 밖에서 운영하는 서비스(SaaS)로는 제공하지 않는다.
- 외부 기여(PR)는 받지 않는다. 버그 제보와 제안은 이슈로만 받는다.
- 제품 코드와 배포 묶음에 GPL·AGPL·LGPL 계열 의존성과 비상업 조건이 붙은 모델·데이터를 넣지 않는다.

## 이유

- 이중 라이선스는 모든 코드의 저작권자가 한 사람이거나, 남의 코드가 모두 허용적 라이선스일 때만 가능하다. 지금 저장소의 작성자와 기여자는 저장소 주인 한 명이고, 의존성은 모두 허용적 라이선스다(`docs/dependencies.md`).
- GPL 계열 라이브러리가 하나라도 들어가면 상용판에 같은 조건이 따라붙어 상용 라이선스를 줄 수 없다. 외부 기여를 받으면 기여자 저작권이 섞여 같은 문제가 생긴다.
- 국가 망 보안체계(N2SF) 모델 2 는 외부 언어모델 연계체계를 기관 안(S 영역)에 둔다. 기관 밖에서 운영하는 서비스는 이 구조와 맞지 않는다.
- 이미 AGPL-3.0-only 로 공개한 판은 그 조건으로 계속 쓸 수 있다. 이 결정은 그 판을 거두지 않는다.

## 의존성을 들일 때

| 조건 | 판단 |
|---|---|
| MIT, BSD, Apache-2.0, BSL-1.0, Zlib, ICU 처럼 허용적 라이선스 | 들일 수 있다. 고지문을 배포 묶음에 넣는다 |
| GPL, AGPL, LGPL(동적 연결 포함), MPL 처럼 조건이 상용판에 따라붙는 라이선스 | 제품 코드와 배포 묶음에 넣지 않는다 |
| 빌드·시험에만 쓰고 배포하지 않는 도구 | 배포하지 않으면 들일 수 있다. `docs/dependencies.md` 에 "배포하지 않음"으로 적는다 |
| 모델 가중치와 학습 데이터 | 상업 이용이 허용되고 출처 표시 조건을 지킬 수 있어야 한다. 비상업 조건이면 넣지 않는다 |

## 영향

- 문서 입력(Phase 11.5)의 PDF 처리는 GPL 인 poppler 를 쓰지 않고 PDFium(BSD) 또는 직접 구현 중에서 고른다.
- 모델과 데이터의 상업 이용 조건은 공개 준비(Phase 7.10)에서 다시 확인한다. 남은 것: 이름 탐지 모델 바탕 모델의 사전학습 말뭉치 승인(ADR 0006), 문장 판별기 바탕 모델 라이선스, 학습 데이터셋별 조건.
- 상용 라이선스와 유지보수 계약 문안은 이 저장소에 두지 않는다.
- 공공기관 도입 인증 경로는 근거 이슈 #191 에 정리했다.
