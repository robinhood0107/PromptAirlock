# 0025. 문장 판별기 경고 모드 봉인 판정: 미채택

상태: 확정 (2026-11-02)

## 결정

ADR 0023 의 경고 모드를 채택하지 않는다. 설정 `sentence_warn` 은 기본값 꺼짐 그대로 두고, 설치 안내와 기본 설정에서 켜지 않는다. 코드는 그대로 남긴다. 켠 경우의 동작(판별 실패 시 거절, 확인 표지, 감사 기록)은 ADR 0023 과 같다.

판정 뒤 모델이나 문턱값을 다시 고르지 않는다. 이번 봉인 셋은 이제 본 셋이므로, 판별기를 고쳐 다시 판정하려면 새 봉인 셋과 새 결정이 필요하다.

## 수치(#195)

측정 전에 고정한 기준(#194 4절) 12개 가운데 8개 통과, 4개 불합격. 구간은 Wilson 95%.

| 항목 | 기준 | 결과 |
|---|---|---|
| 민감 문장 재현율(규칙 또는 판별기) 하한 | 70% 이상 | 65.83%(884/1,292) 불합격 |
| 무작위 정상 문장 경고율 상한 | 5% 이하 | 7.14%(107/1,798) 불합격 |
| 실제 문서 문장 경고율 상한 | 5% 이하 | 1.38%(1,841/139,716) 합격 |
| 범주 재현율 하한(60문장 이상 범주 8개) | 55% 이상 | 5개 합격, 정치적 견해 53.50%·유전 30.37%·인종·민족 28.05% 불합격 |
| 정답 일치도 kappa | 0.8 이상 | 0.891 합격 |

참고

- 자연 분포만 보면 재현율 79.7%(145/182)지만, 범주 낱말이 든 어려운 문장에서는 66.6%(739/1,110)다.
- 정상 경고는 자기소개형 대화(15.9%)와 의학 일반 지식(18.0%)에서 높다.
- 공개 문서 55건 가운데 37건(67.3%)에서 경고가 한 번 이상 뜬다.
- 무작위 정상 문장의 규칙 차단은 3.06%(55/1,798)이고, 그중 42건이 의학 일반 지식 문장이다. 규칙은 이번에 바꾸지 않았다.

## 근거

- 기준은 판정 셋을 보기 전에 고정했다. 떨어진 항목이 있는데 채택하면 기준을 고정한 뜻이 없다.
- 정상 경고율 5.95% 는 업무 문장 열일곱 개 중 하나에서 확인을 묻는다는 뜻이다. 확인이 잦으면 사용자가 내용을 보지 않고 확인을 누르게 되어 경고의 뜻이 없어진다.
- 켜 두지 않아도 규칙(ADR 0016)이 지금처럼 막으므로 보안 수준은 7.8 이전과 같다. 판별기는 막는 쪽이 아니라 경고만 더하는 기능이었다.

## 대안

| 대안 | 거절 이유 |
|---|---|
| 그대로 채택 | 측정 전 기준 4개 불합격 |
| 문턱값을 올려 경고를 줄이고 다시 판정 | 판정 셋을 본 뒤 고르는 것이라 숫자가 부풀어 오른다. 새 셋이 필요하다 |
| 통과한 범주만 켜기 | 범주를 판정 뒤에 고르는 것이라 위와 같다 |
| 코드를 지움 | 다음 판별기가 같은 경로(확인 표지, 판별 실패 거절)를 다시 쓴다. 기본 꺼짐이면 쓰지 않는 사람에게 영향이 없다 |

## 남은 것

- 유전, 인종·민족 범주의 실제 문장과 "저는 ~" 자기소개 문장, 병 이름이 든 설명문을 학습에 더해 다시 만들지는 새 결정으로 정한다. 다시 판정할 때는 이번 셋을 쓰지 않는다.
- 민감정보 규칙이 의학 일반 지식 문장을 막는 원인을 이번 봉인 셋이 아닌 자료로 따로 확인한다.
- 문서 입력(Phase 11.5)에서는 문서 하나에 경고가 여러 번 뜰 수 있으므로 문서 단위로 묻는 방식을 따로 정한다.
