# 0031. 전용 로컬 관리자 출처의 읽기 전용 감사 조회

상태: 확정 (2026-11-23, 사용자 승인 #276)

## 결정

- 설정의 최상위 `admin_history_origin`은 기존 `origins`에 등록한 관리자 전용 출처 하나를 가리킨다. 기본은 비활성이다. 키 교체 출처와 같은 이름은 거절한다.
- 관리자 출처 token은 `/v1/admin/audit/*` 조회에만 쓴다. 대화, 미리보기, 승인, 자격 증명 교체에는 사용할 수 없다. 권한은 출처 이름 일치로 결정하며 출처의 대화 등급 정책과 분리한다.
- 세 조회는 `GET /v1/admin/audit/counts`, `GET /v1/admin/audit/events?page=N`, `GET /v1/admin/audit/egress/<request_id>`다. 상세 request id는 `chatcmpl-pa-`와 소문자 16진수 24자 형식이다. 기존 Bearer 인증, 루프백, 현재 게이트웨이 Host, Origin이 있으면 동일 출처, 중복 인증·Host·Origin 거절을 적용한다. 본문·등급·확인 헤더는 받지 않고, 응답은 `no-store`다. 서버 전체에서 관리자 조회는 한 번에 하나만 실행하며, 초과 요청은 고정 `overloaded` 오류로 거절한다.
- 기본 집계와 이벤트 목록은 최근 24시간만 다룬다. 이벤트는 페이지마다 25건, 40페이지까지다. 고정된 필드 allowlist만 반환하며 `client`, 원문·파일 경로, hash·prev, provider 자격 증명, 복원 mapping, 응답 본문은 제외한다.
- 상세 요청은 최근 구간의 `egress` 이벤트에서 고정 형식 request id가 일치하는 `sent` 한 건만 고른다. provider 규격별 허용 키를 확인한 뒤 요청 본문을 텍스트 필드로 반환한다. `egress` 기록은 provider 호출 전에 만들어질 수 있으므로 응답 상태는 `prepared`, `delivery_confirmed=false`이며 실제 전달 완료로 표시하지 않는다. `egress_answer`는 세부 조회에 포함하지 않는다.
- 읽기 구간은 24시간이다. 검증은 최대 3개의 UTC 일별 세그먼트와 checkpoint에서 수행하며, 총 16 MiB·8,192줄·한 줄 1 MiB를 넘지 않는다. AuditLog 잠금 안에서 `day_`, `last_hash_`, `lines_`, 바이트 수, 마지막 줄 크기와 파일 크기를 복사하고, 잠금 밖에서는 이 복사본을 읽은 세그먼트와 대조한다. 최근 구간의 모든 줄 hash와 내부 prev 연결, 닫힌 세그먼트 checkpoint를 확인하고 오래된 시작 경계의 전 기간 검증은 주장하지 않는다. 전체 보존 로그 검증은 기존 로컬 CLI를 사용한다.
- 검증 상한을 넘으면 집계/목록은 `complete=false`, `status=range_limited`로 건수와 항목 없이 답한다. 오래됐거나 한 건이 큰 상세(128 KiB 초과)는 `out_of_range`로 답한다. 잘못된 hash, 연결 단절, 절단, 부분 읽기는 전체 조회를 실패 처리하며 일부 결과를 반환하지 않는다.
- 성공한 조회와 범위 제한 결과는 본문을 포함하지 않는 `admin_history_access` 이벤트를 먼저 추가한 뒤 응답한다. 이 감사 쓰기가 실패하면 조회 내용을 반환하지 않는다. 무결성 검증 자체가 실패하면 손상된 파일에 덧붙여 쓰지 않고 `unavailable`로 거절한다. retention, 기존 감사 형식, 삭제 정책은 바꾸지 않는다.
- 조회는 provider·Vault를 호출하지 않고 감사 기록도 수정·삭제·내보내지 않는다. O/S 대화 전송 정책과 승인 조건은 바꾸지 않는다.

## 대안

| 대안 | 이유 |
|---|---|
| 보존 로그 전체를 조회 요청마다 검증 | 오래된 세그먼트까지 무제한으로 읽을 수 있다 |
| 일반 대화 출처에 감사 조회 권한 부여 | 대화 출처 token에 관리자 권한이 겹친다 |
| egress answer·복원 본문·hash를 함께 반환 | 요청 조회에 필요하지 않은 S등급 값을 더 노출한다 |
| 페이지를 여러 차례 요청해 전체 내보내기 | 원격 감사 export가 된다 |

## 근거

사용자 결정 #276(2026-11-23). 구현 범위는 D3 #275의 로컬 관리자 조회이며, 브라우저 화면과 승인 목록은 후속 작업이다.

## 보안 영향

조회 권한은 별도로 지정한 기존 Bearer 출처 하나에 한정한다. 요청별 인증 실패와 출처 등급 판정은 그대로 유지하며, 관리자 token은 보호 전송 경로에서 거절한다. 전송 준비 요청만 선택 조회하고 원문 대응·provider 응답·비밀값은 내보내지 않는다.

## 변경 조건

조회 구간·페이지·응답 상한을 바꾸거나 승인 목록·감사 내보내기를 추가하려면 각각 별도 검토와 회귀 시험을 둔다. 전체 보존기간 검색은 요청 처리 중 수행하지 않는다.
