# 0015. 판정 기본값

상태: 확정 (2026-10-05). 탐지 범위는 [0016](0016-detection-coverage.md)이 넓혔다.

## 결정

등급

- C, S, 등급 미확정([0013](0013-grade-identification.md))은 차단한다. O만 내용 검사로 넘긴다.

개인정보 종류별 처리

공식 문서가 이름을 들어 입력하지 말라고 한 정보는 차단한다. 그 밖의 식별자는 가명화한다.

| 종류 | 처리 |
|---|---|
| ApiKey, PrivateKey | 차단 |
| KoreanRrn(주민등록번호) | 차단 |
| CardNumber(신용카드 번호, 새로 추가) | 차단 |
| Person, Organization, KoreanPhone, Email, KoreanBusinessNo, IpAddress, InternalTerm | 가명화 |

- 하나라도 차단 대상이 있으면 요청 전체를 거절한다. 감사 기록에는 종류와 사유 코드만 남기고 값은 남기지 않는다.
- 탐지 결과가 겹치면 하나로 합치고 더 엄격한 처리를 따른다(차단, 가명화, 통과 순).
- 기관이 종류별 처리를 바꾸는 설정은 두지 않는다.

한도

- 질문 본문 64 KiB, 요청당 탐지 결과 512개. 넘으면 거절하며 설정으로 바꿀 수 없다.

## 대안

| 대안 | 거절 이유 |
|---|---|
| 주민등록번호도 가명화 | 공식 문서가 주민등록번호를 이름으로 들어 입력하지 말라고 한다 |
| 개인정보 전부 차단 | 공식 문서는 가명화·익명화를 조치 방법으로 들고, 업무 질의 대부분이 막힌다 |
| 종류별 처리를 기관 설정으로 | 설정 실수 위험이 생기고 선택지 고정 원칙([0012](0012-deployment.md))과 맞지 않는다 |

## 근거

쪽은 인쇄 쪽이다.

| 확인한 내용 | 근거 |
|---|---|
| 주민등록번호, 신용카드 정보, 비밀번호 등의 개인정보와 기관 내부 민감 정보를 입력하지 않는다. 금융 정보(신용카드 번호, 계좌, 비밀번호)와 인증 정보(사용자 이름, 비밀번호, 인증 코드) 입력 금지 | 2023 국가정보원 외부 언어모델 활용 보안 가이드라인 p.30 |
| 가명화·익명화로 실제 개인정보와 기관의 관계를 유추할 수 없게 한다 | 같은 문서 p.30 |
| API 입력에 기관 내부 정보·개인정보가 있는지 확인하고, 가명화·익명화로 누출 시 개인을 식별·연관할 수 없게 한다. 입력은 최소화한다 | 같은 문서 p.42 |
| 인증서 비밀번호, 기관 전자우편 비밀번호 등을 상용 정보통신서비스로 주고받지 않는다 | 국가 사이버보안 기본지침 제67조 ②(p.71) |
| IP주소 현황, 접근권한 정보, 개인정보는 누출금지정보의 예다 | 기본지침 제13조 ②(p.19~20) |
| 상용 언어모델 서비스로 C·S를 다루지 않는다 | 기본지침 제66조 ④(p.70), N2SF 부록 2-2 p.11 |
| 외부 통신 때 개인 식별 정보가 노출되지 않도록 한다(EB-M1) | N2SF 부록 2-2 p.22 |
| 프롬프트 길이·형식 제한, 입력 길이·동시 요청 수 제한 | 국가ㆍ공공기관 보안 가이드북 M14(p.37), M27(p.42) |

- 한도 수치는 공식 문서에 없다. 64 KiB는 Vault IPC frame 상한([0003](0003-vault-ipc.md))과 같은 크기이고 한국어 약 2만 자다. 512개는 64 KiB 기준 평균 128바이트마다 하나라서 정상 문서보다 훨씬 촘촘하며, 넘으면 비정상 입력으로 본다.
- 계좌번호, 인증 정보, 민감정보, 주민등록번호 외 고유식별정보는 [0016](0016-detection-coverage.md)에서 종류로 더하고 차단한다.

## 보안 영향

- 차단 대상의 원문은 Vault에도 저장되지 않는다.
- 차단과 한도 초과는 provider 호출 없이 끝난다.
- 단어 규칙으로 판별할 수 없는 정보의 남는 위험은 [0016](0016-detection-coverage.md)에 적는다.

## 변경 조건

- 공식 문서가 다른 종류를 입력 금지로 들면 차단 목록에 더한다.
- 탐지 정확도 측정에서 가명화 대상의 놓침이 기준을 넘으면 그 종류를 차단으로 바꾸는 것을 검토한다.
