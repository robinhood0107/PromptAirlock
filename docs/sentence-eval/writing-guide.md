# 봉인 판정 셋 작성 지침

문장 판별기(ADR 0022)를 마지막으로 한 번 판정할 때 쓰는 문장 셋을 만드는 방법입니다. 판별기를 만드는 사람은 이 셋을 보지 않습니다. 그래서 이 문서는 작성하는 두 분이 같은 기준으로 쓰고 정답을 표시할 수 있게, 무엇을 어떻게 쓰는지만 적습니다. 예시 문장은 일부러 넣지 않았습니다. 예시를 주면 그 모양을 닮은 문장이 많아지고, 판별기가 그 모양에만 맞춰져도 수치가 좋게 나오기 때문입니다.

## 1. 무엇을 판정하나

Prompt Airlock 은 회사나 기관 사람이 업무 중에 외부 언어모델 서비스에 질문을 보내기 전에, 질문 안의 민감한 내용을 찾아 막거나 가명으로 바꿉니다. 판별기는 그중 "특정한 사람의 민감한 사정"을 단어 하나 없이 돌려 말한 문장을 찾습니다. 판별기만 걸린 문장은 막지 않고 사용자에게 경고합니다(결정 #166).

판정용 문장은 "업무 중에 누군가 채팅창에 실제로 칠 법한 한두 문장"이어야 합니다.

## 2. 민감한 문장(범주 11개)

특정한 사람(나, 가족, 동료, 고객 등 누구인지 가리킬 수 있는 사람)에 관해 아래 사정을 드러내는 문장입니다.

| 범주 | 뜻(개인정보 보호법 제23조, 시행령 제18조) |
|---|---|
| 건강 | 병, 장애, 치료, 복용 약, 임신, 정신 건강, 중독 |
| 신념 | 종교와 신앙 생활, 사상 |
| 노동조합 | 노동조합 가입·탈퇴, 노조 활동 |
| 정당 | 정당 가입·탈퇴, 당원 활동, 선거 출마 |
| 정치적 견해 | 지지하는 정치 세력, 정치적 행동과 의견 |
| 성생활 | 성적 지향, 성 정체성, 성생활 |
| 유전 | 유전자 검사 결과, 유전 질환, 가족력 검사 |
| 범죄 | 전과, 수사, 재판, 형 집행, 보호관찰 |
| 생체 | 지문, 얼굴, 홍채, 목소리, 정맥 같은 생체 정보의 등록·사용 |
| 인종·민족 | 출신 민족, 인종, 이주 배경 |
| 인증 정보 | 비밀번호, 인증 번호, 잠금 해제 문자열 같은 값 자체(사람 대신 계정·장비에 관한 것) |

쓰는 법

- 범주마다 60문장을 씁니다(두 분이 30문장씩). 전체 660문장입니다.
- 그중 3분의 2 이상은 위 표의 대표 단어(병, 교회, 노조, 당원, 전과, 지문 같은 말)를 쓰지 않고 돌려 말합니다. 나머지는 대표 단어를 써도 됩니다.
- 사람을 가리키는 말을 다양하게 씁니다. 이름과 직함, 성과 호칭, 친족(시누이, 사촌 등), "그분", "옆 팀 사람", "저" 같은 말을 섞습니다.
- 말투를 섞습니다. 존댓말, 반말, 메신저 말투, 보고서 말투, 질문 형태("~인데 어떻게 하죠?")를 모두 씁니다.
- 한 문장 안에 민감한 내용이 다른 업무 이야기와 섞여 있어도 됩니다.

## 3. 정상 문장(800문장, 두 분이 400문장씩)

민감한 사정을 드러내지 않는 문장입니다. 판별기가 헷갈리기 쉬운 문장을 많이 넣는 것이 중요합니다.

| 종류 | 개수(한 분당) | 무엇 |
|---|---|---|
| 헷갈리는 정상 | 200 | 위 범주와 주제가 가까운 낱말(병원, 교회, 노조 사무실, 선거, 경찰서, 출입 카드, 외국인 고객 등)이 들어가지만, 특정한 사람의 민감한 사정은 아닌 업무 문장. 사람이 나와도 됩니다 |
| 사람 + 평범한 업무 | 120 | 특정한 사람이 나오는 평범한 업무 문장 |
| 일반 지식 | 40 | 범주에 관한 일반적인 질문("~을 설명해 주세요") |
| 업무 보고 | 40 | 사람이 나오지 않는 보고체 문장 |

## 4. 지키실 것

- 실제 인물, 실제 병력, 실제 계정 값을 쓰지 않습니다. 이름과 값은 지어냅니다.
- 판별기 개발에 쓰인 문장 셋(`tests/fixtures/sentence/`)과 이 저장소의 시험 문장은 보지 않습니다.
- 다른 작성자와 문장을 돌려 보지 않습니다. 정답 표시가 끝날 때까지 각자 씁니다.
- 언어모델 서비스로 문장을 만들지 않습니다. 직접 씁니다.

## 5. 정답 표시

1. 두 분은 각자 쓴 문장을 한 파일로 모읍니다(문장 파일). 정답은 따로 둡니다.
2. 두 분의 문장을 섞은 뒤, 두 분이 모든 문장에 정답을 따로 표시합니다. 정답은 범주 이름 하나 또는 "정상"입니다. 자기가 쓴 문장도 다시 표시합니다.
3. 정답 일치도(Cohen kappa)를 계산합니다(`tests/fixtures/sentence/kappa.mjs`). 0.8 이상이어야 이 셋을 씁니다.
4. 두 분의 정답이 다른 문장은 제3자가 정합니다. 제3자도 판별기를 만들지 않은 사람이어야 합니다.

## 6. 파일 형식과 보관

한 줄에 하나씩 JSON 으로 씁니다(UTF-8).

- 문장 파일: `{"id": "s-0001", "text": "..."}`
- 정답 파일(작성자마다 하나): `{"id": "s-0001", "label": "Health"}`. label 은 `Health`, `Belief`, `LaborUnion`, `PoliticalParty`, `PoliticalView`, `SexLife`, `Genetic`, `Criminal`, `Biometric`, `Ethnicity`, `Credential`, `None` 가운데 하나입니다.

파일은 저장소에 넣지 않고 작성자가 보관합니다. 저장소에는 sha256 만 기록합니다. 판정은 판별기를 고정한 뒤 한 번만 돌리고, 결과는 범주별 개수와 비율만 공개합니다.
