# 봉인 판정 셋 구성 지침

문장 판별기(ADR 0022)를 마지막으로 한 번 판정할 때 쓰는 문장 셋을 만드는 방법입니다. 처음에는 사람 둘이 문장을 새로 쓰는 방식이었는데, 결정 #190 에 따라 학습에 한 번도 쓰지 않은 공개 데이터셋에서 문장을 고르는 방식으로 바꿨습니다. 판별기가 본 적 없는 문장이라는 조건은 같고, 사람이 문장을 지어내는 대신 실제로 쓰인 문장을 씁니다.

## 1. 무엇을 판정하나

Prompt Airlock 은 회사나 기관 사람이 업무 중에 외부 언어모델 서비스에 질문을 보내기 전에, 질문 안의 민감한 내용을 찾아 막거나 가명으로 바꿉니다. 판별기는 그중 "특정한 사람의 민감한 사정"을 단어 하나 없이 돌려 말한 문장을 찾습니다. 판별기만 걸린 문장은 막지 않고 사용자에게 경고합니다(결정 #166).

## 2. 문장을 가져오는 곳

NIA 데이터 공유 플랫폼(aihub.or.kr) 데이터셋 가운데 학습(14종)에 쓰지 않은 11종입니다. 데이터셋을 통째로 떼어 두므로, 같은 출처의 다른 문장이 학습에 섞이지 않습니다.

|---|---|---|
| 71848 | 법률 형사법 LLM 사전학습 및 Instruction Tuning 데이터 | 범죄 |
| 71305 | 한국어 공감형 대화 | 개인 사정 |
| 71630 | 한국어 멀티세션 대화 | 개인 사정 |

| 71791 | 진로문장완성검사 텍스트 데이터 | 자기 진술 |

- 겹침 검사: `training/sentence/overlap.py` 가 학습 14종과 공백만 다른 같은 문장을 찾습니다. 겹친 문장은 후보에서 뺍니다.

## 3. 민감한 문장(범주 11개)

특정한 사람(나, 가족, 동료, 고객 등 누구인지 가리킬 수 있는 사람)에 관해 아래 사정을 드러내는 문장입니다.

| 범주 | 뜻(개인정보 보호법 제23조, 시행령 제18조) |
|---|---|
| 건강 | 병, 장애, 치료, 복용 약, 임신, 정신 건강, 중독 |
| 신념 | 종교와 신앙 생활, 사상 |
| 노동조합 | 노동조합 가입·탈퇴, 노조 활동 |
| 정당 | 정당 가입·탈퇴, 당원 활동, 선거 출마 |
| 정치적 견해 | 지지하는 정치 세력, 정치적 행동과 의견 |
| 성생활 | 성적 지향, 성 정체성, 성생활 |
| 유전 | 유전자 검사 결과, 유전 질환, 가족력 검사 |
| 범죄 | 전과, 수사, 재판, 형 집행, 보호관찰 |
| 생체 | 지문, 얼굴, 홍채, 목소리, 정맥 같은 생체 정보의 등록·사용 |
| 인종·민족 | 출신 민족, 인종, 이주 배경 |
| 인증 정보 | 비밀번호, 인증 번호, 잠금 해제 문자열 같은 값 자체(사람 대신 계정·장비에 관한 것) |

## 4. 후보 고르기(측정 전 고정, #194 4절)

- 400자 이하이고 학습 문장과 겹치지 않는 문장만 씁니다.
- 무작위 후보: 데이터셋마다 180문장(사람을 가리키는 말이 있는 문장 150, 없는 문장 30), seed 20261102. 정상 문장 경고율과 자연 분포 재현율에 씁니다.
- 범주 표적 후보: 범주 11개마다 범주 낱말이 든 문장을 400문장까지, 데이터셋을 돌아가며 고릅니다(사람 표지 있음 3 : 없음 1). 범주별 재현율에 씁니다.
- 정답이 붙은 뒤 문장이 60개 미만인 범주는 합격 판정에서 빼고 개수와 비율만 참고로 냅니다(결정 #190).

## 5. 정답

- 7.8-2 실제 셋과 같은 절차로 정답을 붙입니다. 정답은 범주 이름 하나 또는 `None` 입니다.
- 300문장(자연 분포 무작위 100, 민감 정답 100, 표적 후보 중 정상 정답 100)을 같은 절차로 따로 다시 표시해 Cohen kappa 를 계산합니다(`tests/fixtures/sentence/kappa.mjs`). 0.8 이상이어야 이 셋을 씁니다. 두 정답이 다른 문장은 다시 판정한 값을 씁니다.
- label 은 `Health`, `Belief`, `LaborUnion`, `PoliticalParty`, `PoliticalView`, `SexLife`, `Genetic`, `Criminal`, `Biometric`, `Ethnicity`, `Credential`, `None` 가운데 하나입니다.

## 6. 판정과 보관

- 판정은 `training/sentence/sealed_judge.py judge` 로 판별기를 고정한 뒤 한 번만 돌립니다. 셋을 본 뒤 문턱값이나 모델을 다시 고르지 않습니다.
- 원문, 후보, 정답 파일은 저장소에 넣지 않습니다. 저장소와 공개 이슈에는 해시, 범주별 개수, 비율, 구간만 남깁니다.
